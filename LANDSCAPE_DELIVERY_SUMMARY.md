## 🚀 Quick Deployment

### 1. Copy Files
```bash
# From this location
cp -r /home/weissto_local/git/opendesk_git/opendesk-edu-website/LANDSCAPE* ./your-website/
cp -r /home/weissto_local/git/opendesk_git/opendesk-edu-website/src/ ./your-website/
cp /home/weissto_local/git/opendesk_git/opendesk-edu-website/messages/en.json ./your-website/messages/
```

### 2. Install Dependency
```bash
cd your-website
npm install framer-motion@^11.0.0
```

### 3. Add Navigation
```typescript
// In your navigation config
{ name: 'Landscape', href: '/landscape' }
```

### 4. Go Live
```bash
npm run build
npm run start
# Visit: https://your-site/landscape
```
